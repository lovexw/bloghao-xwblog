会员 / 积分 / 排行榜(P1)与文章访问密码(C)均已落地(用法见 docs/GUIDE.md §15,防线约定
见 AGENTS.md「会员体系」「文章访问密码」两节)。当初的 A·B 双机并行分工、文件所有权与
过程叙事已随收官失效,本文只保留有长期约束力的三样:已拍板口径、契约现状速查、变更纪律。

## 已拍板口径(2026-10-07 用户定,后续变更在这里回填)

- 注册门槛:用户名 + 密码 + 可选邮箱 + 蜜罐限流(Turnstile 不上,见 ROADMAP C7)
- 积分规则:评论 +2(过审才计、同一评论只计一次、单日 10 条上限)、每日登录 +1;
  数值只改 `src/points.ts` 常量表一处
- 升级路径未拍板(P2/P3);支付闭环、兑换码、会员积分明细端点均未做
- 后台积分调整(pointsDelta + note)延后 P1.5——账本 `reason='adminAdjust'` 已在 schema 预留,届时只加 API
- 首页排行挂件已下线:榜单收敛到 /rank 页(`HomeData.rank` 字段与 `rankCard()` 构建器已删)
- 撤销的候选键/端点,别复活:`membersAllowRegister`(注册随 membersEnabled 走)、
  `/api/public/rank`(走 SSR 的 RankData)、`/api/member/points`(有真实消费方再走契约变更)

## 契约现状速查(以代码为准,此处只列口径)

- 枚举:`minTier = all | member | coffee | top`(脏值归 all,宁漏勿锁死);`tier = normal | coffee | top`
- registry:`MemberData` / `RankData` / `MemberView` / `RankEntryView` 定义见
  `src/themes/registry.ts`;`member()` / `rank()` 是 ThemeModule 可选成员,缺省时 pages.ts
  兜底通用版——主题作者可只实现部分页面
- 会话:会员独立 Cookie `xw_member_session`,与管理员 `bloghao_session` 互不干扰
- 端点出参形状见 docs/API.md,不在本文重复:会员四端点(register/login/logout/me)、
  后台 `GET/PUT /api/admin/members`(PUT 缺键即保留;列表出参剥 password_hash/salt,同
  postAdminView 口径)
- settings:`membersEnabled`('1'/'0' 默认 '0';关 = /member、/rank 一律 404,已锁文章仍按
  minTier 生效)、`rankTopN`(1–50 默认 '10')
- schema:`posts.min_tier TEXT NOT NULL DEFAULT 'all'`、`comments.member_id`;members /
  member_sessions / member_points_log 三表(临时凭证表不进备份)
- email 只在 `/api/member/me`(本人视角)与管理口径返回,公开面(排行榜 / 评论徽标)一律不含
- 挂件下线后的保留面:/rank 页 + `rankListHtml` / `.rk-list` / `.rk-item` 结构 + `rankTopN` 设置

## 契约变更纪律

registry 类型、端点出参、settings 键、schema 列,任一形状变更 = 契约变更:先改本文与
AGENTS.md 对应条款再动代码,涉及付费墙 / 防泄漏语义的按 AGENTS.md 清单逐项核对。
